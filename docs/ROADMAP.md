## 判定 1（2027-02-15・公開から 3 か月）

PLAN §13 の指標をそのまま使う。

| 指標 | ライン | どこで見る |
|---|---|---|
| verified 用語 | 1,500 | データ |
| Google にインデックスされた用語ページ | 1,000 | Search Console |
| 月間ユーザー | 1,000 | GoatCounter |
| Anki デッキの DL | 200 | AnkiWeb |
| 「助かった」の声 | 10 件 | issue・DM・SNS |

- 届いた → v2 へ。
- 届かない → 原因を 2 つに分ける。**来ていない**（Search Console の表示回数が少ない）なら配布と SEO、**来ても使わない**（来るのに 0 件検索が多い・すぐ帰る）なら中身。両方いっぺんに直さない。

## v3（候補）— 数学英語の標準の参照先に

- 公開 API（静的 JSON のまま、版をつける）。
- 同じ仕組みで別の言語ペア（例：中国語⇄英語・韓国語⇄英語）。データの型・監査の流れ・用例コーパスはそのまま使える。
- 「数学の検証・AI 基盤」の入口として：用語の対応と根拠付きの用例は、言語モデルの評価データになる（CC0 なので誰でも使える）。

## 測るもの（v1.0 で入れる）

| 道具 | 何が分かる | 費用 | プライバシー |
|---|---|---|---|
| **GoatCounter** | 人数・どの用語ページが見られたか・どこから来たか・**0 件検索の語**（イベント） | 無料（個人・中小の公開サイトは無料で使える。多ければ自前で動かせる） | クッキーなし・個人データを保存しない |
| **Google Search Console** | どんな検索語で表示・クリックされたか・インデックス数 | 無料・スクリプト不要 | サイトに何も入れない |

Cloudflare Web Analytics も無料でクッキーなしだが、イベントが無いので 0 件検索を数えられない。Google Analytics は入れない（クッキーと同意バナーが要る・サイトの方針に合わない）。

## ずっと変わらないこと

- 無料・広告なし・ログインなし・有料機能なし（PLAN §4）。
- データは CC0・コードは MIT。
- 出典のない語は出さない。直訳を出さない（STYLE.md・CLAUDE.md の絶対ルール）。
- 範囲は v1 で固定。広げるのは v2 の issue に積んでから（PLAN §13 のリスク表）。
