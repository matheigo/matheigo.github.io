増減表

sign chart
ぞうげんひょう 別の言い方　sign diagram

対応する語がない　米国の教材に、増減表に当たる定型の表は出てこない。同じ判断は first derivative test（第 1 次導関数判定法）で行い、f′ の符号を数直線に書いた sign chart を使う。

答案では

表だけで済ませず、f′ の符号の変化と定理の名前で理由を書く。AP Calculus の CED は、sign chart は答えを見つける道具として役に立つが、理由（justification）の点は定義や定理に結びつけて書いて得る、としている。下の例文の書き言葉が、その形。

定義

導関数の符号を区間ごとに並べ、もとの関数の増減と極値を読み取る表。

A number line, or table, marked with the sign of the derivative on each interval, used to find where a function rises and falls.

例文

話し言葉 Make a sign chart for f prime and see where it changes from plus to minus. f′ の増減表を書いて、正から負に変わるところを見て。
書き言葉 Since f′ changes from positive to negative at x = −1, f has a local maximum there by the first derivative test. 増減表より、x = −1 の前後で f′ が正から負に変わるので、f は x = −1 で極大となる。

よく使う言い方

make a sign chart 増減表を書く f prime changes sign at x = 1 x = 1 の前後で f′ の符号が変わる

言い間違えやすいところ

increase-decrease table は直訳で、用例コーパスにも CED・OpenStax にも出てこない。

極大・極小は local maximum・local minimum（CED は relative extrema とも書く）。区間全体の最大・最小は absolute maximum・absolute minimum。

凹凸は concave up・concave down。「上に凸」を convex upward と直訳した形は用例コーパスに出てこない。
