増減表

ぞうげんひょう
sign chart
別の言い方　sign diagram

対応する語がない　米国の教材に、増減表に当たる定型の表は出てこない。同じ判断は first derivative test で行う。

答案では

表だけで済ませず、f′ の符号の変化と定理の名前で理由を書く（AP Calculus の CED）。

Since f′ changes from positive to negative at x = −1, f has a local maximum there by the first derivative test.

増減表より、x = −1 の前後で f′ が正から負に変わるので、f は x = −1 で極大となる。

定義

導関数の符号を区間ごとに並べ、もとの関数の増減と極値を読み取る表。

A number line, or table, marked with the sign of the derivative on each interval, used to find where a function rises and falls.

言い間違えやすいところ

increase-decrease table は直訳で、講義にも教科書にも出てこない。

凹凸は concave up・concave down。「上に凸」を convex upward と直訳した形は、講義にも教科書にも出てこない。

習う時期

日本数II、数III 米国AP Calculus AB, Calculus I
