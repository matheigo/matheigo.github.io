## 決まり（ユーザーの決定 2026-10-10）

1. 色: 白地に黒の文字。瑠璃色 #1E50A2 は写像の矢印・リンク・主ボタンだけ。補足の文字 #4A4F57、罫 #D9DCE1、図の軸 #8B9099。
   ダークモード: 地 #111318、文字 #ECEDEF、補足 #A5ABB5、罫 #2A2E35、瑠璃 #8DB0F0。
2. 書体: 英語と数式は STIX Two Text、日本語は BIZ UDPMincho（Google Fonts、display=swap）。ほかの書体は使わない。
3. mapping は写像の線で描く: exact は実線の矢印、near は破線の矢印、none は点線と白丸。
   ラベルの文字（1対1で対応・近いが同じではない・対応する語がない）も線の横に残す（線の形と色だけに頼らない）。
4. トップ: 見出し「数学は同じ。言葉が違う。」、写像の図（定積分・代入する・微分係数・上に凸・増減表）、検索、収録数の一文、場面から引く。
   図の矢印は開いたときに一度だけ引かれる。prefers-reduced-motion では動かさず、止まった状態でも意味が分かる。
5. 用語ページ: 見出しの写像の線、本文 680px の 1 段と右の欄外（習う時期・関連語・出典）。スマホは縦に並べ、写像の線も縦。
   見本の曲線の図はデータに無いので作らない（図をデータに足すのはスキーマの変更なので別に決める）。
6. 根拠の件数（evidence）は、話し言葉・書き言葉ごとに帯グラフ 1 本（言い方ごとに黒と灰で塗り分け、件数を数字でも書く）。
7. 守ること: Lighthouse のモバイル 95 以上、検索は 1 秒以内、キーボード操作とフォーカス表示、スマホ幅で横スクロールしない、
   pnpm validate・test・build が通る。
